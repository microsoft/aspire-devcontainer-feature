
# Aspire

A language-neutral devcontainer feature that installs the Aspire CLI and shared VS Code configuration. Aspire manages its bundled .NET components; a separate .NET SDK is not required.

Starting with version 3, language-specific tooling such as C# Dev Kit is configured by the consuming devcontainer, not this feature.

See the [feature documentation](src/aspire/README.md) for usage and the `installCli` option.
